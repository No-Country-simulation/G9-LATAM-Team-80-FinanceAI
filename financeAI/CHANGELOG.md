# Changelog

## 0.1.0

- Estructura inicial React + Vite + TypeScript.
- Arquitectura modular por dominio.
- Pantallas principales del MVP de Salud Financiera.
- Analisis financiero local con datos demo.
- Estilos basados en las referencias de `imagenes-de-guia`.
- Subvistas internas para nueva transaccion, importacion CSV, nuevo analisis,
  nuevo presupuesto, detalle de recomendacion y proyeccion de impacto.
- Pestañas funcionales para analisis, recomendaciones y configuracion.
- Subvistas de Perfil para editar informacion, administrar cuentas bancarias,
  administrar tarjetas de credito e importacion manual.
- Ajustes globales de responsividad para escritorio, tablet y movil.
- Sidebar responsivo convertido a drawer movil con overlay y boton de menu en topbar.
