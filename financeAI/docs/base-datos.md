# Base De Datos

Para el MVP la persistencia puede iniciar con:

- Usuarios.
- Transacciones.
- Analisis financieros.
- Presupuestos.
- Recomendaciones generadas.
- Archivos importados.

La base de datos es opcional segun los requisitos del hackathon, pero conviene
documentarla si se persiste historial de analisis.
